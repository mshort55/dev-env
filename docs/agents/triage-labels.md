# Triage labels

Each triage role uses the GitHub label of the same name.

| Role and GitHub label | When to use it |
| --- | --- |
| `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | The reporter needs to provide more information. |
| `ready-for-agent` | The issue has enough detail for an agent to implement independently. |
| `ready-for-human` | The issue requires human implementation. |
| `wontfix` | A maintainer has decided to close the issue without implementing it. |
